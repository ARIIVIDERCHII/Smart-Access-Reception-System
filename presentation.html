Concept & Solution

従来の課題

  • 物理ICカードの紛失・貸し借り
  • 手動検温によるタイムロス
  • 勤怠システムの打刻忘れ

提案システム

  • カメラを見るだけの完全手ぶら認証
  • 赤外線センサーによる自動検温
  • 入退室状態を自動で記録・可視化

1. Edge-AI Face ID

高性能な顔認識モデルをRaspberry Pi上でローカル実行。ネットワーク遅延なしで瞬時に個人を特定します。

認証成功時には、PS1風のレトロなパーティクル（粒子）アニメーションで顔が再構築されるUIを採用。毎日の入館処理に「楽しさ」と「近未来感」を演出します。

2. Hardware IoT

Raspberry PiのGPIOおよびI2C通信をフル活用し、ソフトウェアと現実空間を接続。

顔認証と同時にMLX90614赤外線センサーが非接触で体温を測定。正常体温（37.5℃以下）であることが確認された場合のみ、リレー回路を通じて物理的なゲートをオープンします。

3. Campus Map

単なるログ記録ではなく、システムがユーザーの「入室」と「退室」状態を自動でトラッキング。

Webダッシュボード上のマップで、ユーザーのアバターが「HOME」と「INSTITUTE」のゾーン間を物理アニメーションで飛び交う、ゲーミフィケーション要素を取り入れました。

4. Active Security

未登録の人物がカメラの前に3秒以上滞在した場合、システムは即座に「不審者（Intruder）」として検知。

顔写真を自動キャプチャし、LINE Notify APIを通じて管理者グループへ警告メッセージと画像を瞬時にプッシュ通知します。
